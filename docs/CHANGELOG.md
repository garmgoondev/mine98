### 🐛 버그 수정 (Bug Fixes)
- **게임 종료 결과 모달 닫기 버그 해결**:
  - 게임 종료 후 상단 우측 `X` 닫기 버튼 또는 `판 둘러보기` 버튼 클릭 시 모달이 닫히지 않고 화면에 고정되던 이슈 수정 (`GameResultModal`에 `isOpen` prop 연결 및 검증 로직 반영).

  - 판 둘러보기를 위해 모달을 닫은 유저가 언제든 다시 결과를 확인할 수 있도록 하단 컨트롤 바에 **`🏆 결과 다시 보기`** 버튼 추가.

## [v1.0.0] - 2026-10-08

### 🚀 최초 공식 런칭 (Initial Production Release)
- **도메인**: `https://mine98.com` Cloudflare Pages 글로벌 Edge 배포.
- **윈도우 98 레트로 UI**: 3D 베벨 프레임, 7세그먼트 LED 숫자 카운터, 4가지 표정의 스마일리 페이스 버튼.
- **Web Audio API 오실레이터 사운드**: 외부 에셋 다운로드 0B, 브라우저 실시간 합성 사운드 구현.
- **사내망/학교 방화벽 안심 보스 키 (Boss Key)**: `ESC` / `~` 키를 누르면 0.01초 만에 마이크로소프트 365 엑셀 스프레드시트로 화면 및 탭 타이틀/파비콘 위장.
- **첫 수 100% 안전 보장**: 첫 클릭 좌표 주변 9칸 안전 오프닝 알고리즘.
- **스피드런 코드 (Chording)**: 깃발 개수 충족 시 숫자 클릭으로 주변 안전 칸 원터치 자동 개방.
- **난이도 3종**: 초급(9x9, 10지뢰), 중급(16x16, 40지뢰), 고급(30x16, 99지뢰).
- **SEO & 검색엔진 등록**:
  - 구글 서치 콘솔(`sc-domain:mine98.com`) DNS TXT 인증 및 사이트맵 제출.
  - 네이버 서치어드바이저 소유확인, 사이트맵 등록, 메인 수집 요청 완료.
  - 1-2-1 / 1-2-2-1 공략 가이드 및 FAQ 아코디언 온페이지 마크업 탑재.
  - 1호 웹오목(`webomok.com`)과 2호 웹지뢰찾기(`mine98.com`) 상호 맞교환 링크 배너 탑재.
